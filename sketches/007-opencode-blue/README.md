# Variant: OpenCode Blue

## Design stance
Your content wearing the OpenCode website's exact design language: near-black `#0c0c0e` background, monospace everywhere (Berkeley Mono stack), sharp corners (radius 0), iOS-blue accent `#007aff`, Apple system status colors, thin `#38383a` borders. The homepage follows opencode.ai's page flow: badge → h1 → install-style tabs → stat figures → "what is" → FAQ accordion → subscribe.

## Key choices
- Layout: opencode.ai's structure mapped to your content — hero tabs become your 4 offers (dev service / saas tools / games / support), stats become the figure band (101 repos / 150+ stars / 80 videos / 15+ yrs / PyATL), plus "What is Burnsedia?", project cards, build log rows, FAQ, split CTA, newsletter
- Typography: 100% monospace like opencode.ai
- Color: opencode's exact tokens (#0c0c0e / #161618 / #1c1c1f / #007aff / #a1a1a6 / #38383a) — your pink is replaced by iOS blue
- Interaction: hero tabs, FAQ accordion, count-up stats, newsletter with inline success

## Trade-offs
- Strong at: instantly recognizable as "the opencode website"; clean, professional, Apple-adjacent polish; the tabbed hero is a great conversion pattern
- Weak at: loses your darksynthwave pink identity — this reads as OpenCode's brand, not yours

## Best for
If you want to look like a serious open-source product site with maximal OpenCode DNA and are okay trading the pink for iOS blue.
