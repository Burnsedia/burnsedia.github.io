# Variant: Builder Storefront (balanced)

## Design stance
Your live look (hexagon hero, rounded 8px cards, Inter body, plain h2 sections) with terminal accents — mono section tags (`$ ls ~/store`), a bottom status bar, and status dots. The store is one prominent shelf among equals: content leads, the store is one section away.

## Key choices
- Hexagon logo hero (cyan ring) + "I build shit that works" + typing + "Explore the store" CTA
- Live "currently building" strip (mono, status dot)
- Store shelf with type badges + status dots + price + filter
- Productized services as flat-rate cards, membership tier ladder, art+music row
- Terminal accent = bottom status bar + mono section labels only

## Trade-offs
- Strong at: closest to the current site; store is discoverable but not pushy; content-first
- Weak at: the store competes with the build log for attention (less "sell" energy)

## Best for
The recommended hybrid — content business first, storefront one click away.
