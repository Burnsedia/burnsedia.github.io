# Variant: Builder's Dashboard

## Design stance
A dense, tool-like dashboard: stats up top, live build strip, list-style build log, and a persistent sidebar that surfaces revenue streams and newsletter on every scroll. Maximum information density in one viewport.

## Key choices
- Layout: compact hero → stat band → live build strip → two-column (post list + sticky sidebar with products/membership/newsletter)
- Typography: sans with tighter sizes; dates and prices in mono; list rows instead of cards to fit more
- Color: same palette; amber "Hire Me" button is the highest-contrast action; green left-border on the live strip
- Interaction: sticky sidebar follows scroll; newsletter form inline success; product list with live/waitlist badges

## Trade-offs
- Strong at: showing everything at once (proof + products + content); conversion-friendly — revenue streams always visible; feels like a working system
- Weak at: denser, busier; less editorial breathing room; sidebar competes with the build log for attention

## Best for
A "everything in one screen" homepage where stats, revenue, and content all need visibility — good for the builder-in-public audience AND for pushing products without a separate storefront page.
