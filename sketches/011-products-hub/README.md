# Variant: The Store (products hub page)

## Design stance
The dedicated `/products` page — the store as a real destination, not a homepage section. Grouped shelves (Services / SaaS / Games / Art) with mono sub-labels, a top filter, and a "not sure?" fallback CTA. Same hybrid theme as 009/010.

## Key choices
- Page header: `$ cd ~/store` → "The Store" + filter
- Four grouped shelves, each a mono label + h2 + card grid
- Full catalog: services, SaaS (boomerbill/nerdtime/BulkPost/Virtue Tracker), games (32bit-Spacer/The Hive), art/skills
- "Not sure what you need?" fallback (book a call / email)

## Trade-offs
- Strong at: a browsable, complete catalog; the funnel's buy destination
- Weak at: not a homepage — needs the homepage to drive traffic to it

## Best for
The /products route — pair with 009 (balanced homepage) so the homepage shelf deep-links here.
